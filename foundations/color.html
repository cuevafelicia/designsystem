Accessibility

Contrast checks

Every text token was checked against the backgrounds it actually sits on. Body text needs 4.5 : 1 (AA). Large text and UI parts like focus rings need 3 : 1.

Implementation

Use the tokens in CSS

Load tokens.css before Bootstrap overrides and components. Figma names like color/bg/page become --color-bg-page.

tokens.css (color)
/* ---------- Collection 1: Primitives ---------- */
:root {
  /* color */
  --color-plum-900: #231123;
  --color-plum-700: #3D2A3D;
  --color-plum-500: #5A4A5A;
  --color-raspberry-700: #5E1735;
  --color-raspberry-500: #82204A;
  --color-raspberry-100: #F6E3EB;
  --color-teal-700: #3E6B6B;
  --color-teal-500: #558C8C;
  --color-teal-100: #DCECEC;
  --color-gold-500: #E8DB7D;
  --color-gold-100: #FAF5D6;
  --color-alice-50: #EFF7FF;
  --color-white: #FFFFFF;
  --color-black: #000000;
  --color-annotation-redline: #E31C5E;
  ...
}

/* ---------- Collection 2: Tokens (modes: Desktop, Tablet, Phone) ---------- */
:root {
  /* color / bg */
  --color-bg-page: var(--color-alice-50);
  --color-bg-surface: var(--color-white);
  --color-bg-inverse: var(--color-plum-900);
  --color-bg-tint-teal: var(--color-teal-100);
  --color-bg-tint-raspberry: var(--color-raspberry-100);
  --color-bg-tint-gold: var(--color-gold-100);

  /* color / text */
  --color-text-default: var(--color-plum-900);
  --color-text-muted: var(--color-plum-500);
  --color-text-inverse: var(--color-alice-50);
  --color-text-on-primary: var(--color-white);
  --color-text-accent: var(--color-raspberry-500);
  --color-text-highlight: var(--color-gold-500);

  /* color / action */
  --color-action-primary: var(--color-raspberry-500);
  --color-action-primary-hover: var(--color-raspberry-700);
  --color-action-secondary: var(--color-teal-500);
  --color-action-highlight: var(--color-gold-500);

  /* color / border */
  --color-border-default: var(--color-plum-900);
  --color-border-focus: var(--color-teal-500);
  --color-border-inverse: var(--color-alice-50);
  ...
}

Do

  • Use tokens like var(--color-text-default) in components.
  • Pair plum text with alice, white, gold or tint backgrounds.
  • Keep raspberry for actions and accents so it stays meaningful.

Don't

  • Hard-code hex values inside components.
  • Put teal or gold text on white or alice; it fails contrast.
  • Use the annotation red outside the specs.
