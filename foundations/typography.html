Type pairing

Bungee + IBM Plex Sans

This is Hierarchy 3 from my type hierarchies page: a 1.2 Minor Third scale on a 16px base, made with typescale.com. Bungee brings the playful, arcade feel to display text; IBM Plex Sans keeps long reading calm. IBM Plex Mono covers code and spec labels.

Display

Aa

Bungee Regular 400. Headings, card titles, stats, stickers.

Body

Aa

IBM Plex Sans 400, 500, 600, 700 and italics. Body, UI labels, buttons.

Mono

Aa

IBM Plex Mono 400 and 600. Code and spec annotations.

Do

  • Use one H1 per page, then go in order without skipping levels.
  • Keep paragraphs between 45 and 75 characters wide.
  • Set sizes in rem so browser zoom and text resizing work.

Don't

  • Set long paragraphs in Bungee; it is a display face.
  • Use all caps for anything longer than a label.
  • Go below 13.33px for text people need to read.
