Versions

Four versions, one for every background

These are the same four files from my logo guidelines, and the same four variants in the Figma Logo component set (Version = Color, Black, White, Reverse) plus the Favicon component.

1. Color (primary)

Light backgrounds
On white
On Alice Blue
On Midnight Violet

When to use

  • The default choice whenever full color is possible on white or Alice Blue.
  • Light website headers, business cards, slide title pages.

Configuration

  • Dark Raspberry mark, Midnight Violet wordmark, Dark Cyan and Light Gold accents.
  • Never on dark backgrounds: the mark and wordmark disappear (third tile). Use the reverse version.

2. Black and White

Light and dark
Black on light
White on dark

When to use

  • One-color printing: stamps, engraving, laser cutting, embroidery.
  • Over photography where color would clash.

Configuration

  • Two files: black for light backgrounds, white for dark ones.
  • Flat color only, no tints or gradients. Aspect ratio 386 : 218.

3. Reverse

Dark backgrounds
On black
On Dark Cyan
On white

When to use

  • Dark bands and footers, like the footer on every page here.
  • Dark merchandise, stickers and splash screens.

Configuration

  • Alice Blue artwork on its own rounded Midnight Violet panel, so it also works as a badge on light backgrounds.
  • Keep the panel. Aspect ratio 473 : 343.

4. Favicon

Tabs and app icons
Logo | Side Quest SDS
Logo | Side Quest SDS

Every page of this site uses the same favicon file in its tab.

When to use

  • Browser tabs, bookmarks and home-screen shortcuts.
  • Profile pictures and any square space where the wordmark is unreadable.

Configuration

  • 512 x 512 artboard, mark only, on its own Alice Blue rounded tile so it shows on light and dark browser chrome.
  • In Figma it is the Favicon component next to the Logo set.

Scale

Sizing and clear space

The files are vector, so they scale to any size. These limits keep the tagline and the thin orbit ring readable.

Recommended widths (color logo)

Clear space

Keep an empty margin on every side equal to the height of the orbit circle, about a quarter of the logo height.

Rules

Using the logo

Pick the version by background first, then by how many colors the job can print.

HTML
<!-- Favicon in the <head> of every page -->
<link rel="icon" type="image/svg+xml" href="assets/favicon.svg">

<!-- Follow the visitor's light / dark setting -->
<picture>
  <source srcset="assets/fc-studio-logo-reverse.svg"
          media="(prefers-color-scheme: dark)">
  <img src="assets/fc-studio-logo-color.svg" alt="FC Studio"
       style="width: clamp(140px, 30vw, 320px); height: auto;">
</picture>

Do

  • Scale proportionally with the aspect ratio locked.
  • Use the SVG files so edges stay crisp.
  • Use the reverse logo on plum and dark photos.
  • Swap to the favicon below 140px wide.

Don't

  • Stretch, skew, rotate or outline the logo.
  • Recolor it outside the palette.
  • Add drop shadows, glows or gradients.
  • Put the color logo on dark backgrounds.
