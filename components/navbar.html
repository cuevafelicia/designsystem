Accessibility

Accessibility guidelines

The navbar is on every page, so mistakes here repeat everywhere.

  • Landmark and label1.3.12.4.1Use <nav aria-label="Main">. Add a "Skip to content" link before it that jumps to <main>.
  • Mark the current page1.3.14.1.2The active link gets aria-current="page", not just the gold style, so screen readers announce it.
  • Menu button4.1.2The toggler has aria-label="Toggle navigation", aria-controls and aria-expanded, which Bootstrap updates when it opens.
  • Keyboard order2.1.12.4.3Tab moves brand, links, then the button in reading order. Nothing is hidden from keyboard users when the menu is open.
  • Visible focus2.4.7Links and the toggler show the 3px teal focus ring.
  • Brand image1.1.1The favicon next to the brand name is decorative (alt="") because the text already says the name.
  • Tap targets2.5.8Links are 33px tall and the menu button is 60 x 44px, all above the 24px minimum, so they are easy to tap on phones.

Do

  • Keep it to 4 or 5 links plus one button.
  • Use the same order on every page.
  • Use the accent button for the one call to action.

Don't

  • Rely on color alone to show the current page.
  • Hide important links only in the phone menu.
  • Make the sticky bar taller than about 90px.
