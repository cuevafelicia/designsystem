Variants and states

The Figma Button set has 15 variants: Type (Primary, Secondary, Accent) x State (Default, Hover, Pressed, Focus, Disabled). It extends Bootstrap's .btn, so it keeps Bootstrap sizing and behavior.

Code

HTML and CSS

Add .btn .btn-fc to a link or button, then a type modifier.

HTML
<!-- Primary -->
<a class="btn btn-fc" href="#solution">See the solution</a>

<!-- Secondary and accent -->
<button type="button" class="btn btn-fc btn-fc-secondary">Play the prototype</button>
<a class="btn btn-fc btn-fc-accent" href="patterns/case-study.html">Live page</a>

<!-- Disabled: use the attribute, not just the class -->
<button type="button" class="btn btn-fc" disabled>Coming soon</button>

Accessibility

Accessibility guidelines

Buttons are how people move through the case study, so they need to work for keyboard, screen reader and touch users.

  • Use the right element4.1.2Use <a> when it goes to a page or section and <button> when it does something on the page. Both get the same styles.
  • Say what happens2.4.42.5.3Write labels like "See the solution", not "Click here". The visible text must be part of the accessible name. Icons get aria-hidden="true".
  • Keep contrast1.4.31.4.11Every label passes AA: white on raspberry is 9.3 : 1, plum on gold is 12.6 : 1. The 3px plum border keeps the shape visible on any background.
  • Show focus2.4.72.4.11The 3px teal outline with a 4px offset is never removed. It shows on keyboard focus only, using :focus-visible.
  • Big enough to tap2.5.8Buttons are 51px tall, well above the 24px minimum target size.
  • Disable for real4.1.2Use the disabled attribute on buttons. For links, remove the href and add aria-disabled="true". Explain nearby why it is unavailable.
  • Respect reduced motion2.3.3The lift and press animations turn off when someone has reduced motion turned on.

Do

  • Use one primary button per section.
  • Pair a primary with a secondary for two choices.
  • Keep labels short: 1 to 4 words.

Don't

  • Put two primary buttons side by side.
  • Use the accent button for destructive actions.
  • Remove the focus outline or the border.
